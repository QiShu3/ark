## 关键开发里程碑

### 阶段一：项目初始化
- 技术选型：React 18 + TypeScript + Vite（前端），FastAPI + Python（后端）
- 数据库：PostgreSQL
- 基础架构：前后端分离，RESTful API
- 认证系统：JWT Token

### 阶段二：核心引擎
- 统一专注工作抽象：FlashCard / Choice / Input / TaskFocus
- 多阶段工作流引擎：专注 + 休息交替
- 工作流结算与数据统计
- 状态管理：FocusWorkProvider

### 阶段三：学习模块
- 词汇学习系统：新词 + 复习 + 错词本
- FSRS 算法：智能间隔重复调度
- ERC 阅读训练：文章 + 选择题 + 复习
- 题库导入：种子数据管理

### 阶段四：目标管理
- 任务系统：创建、编辑、周期设置
- 事件系统：长期目标与日程安排
- 应用任务：学习模块自动纳入任务
- 成就系统：全局成就 + 事件成就

### 阶段五：体验优化
- 沉浸式 UI：角色立绘 + 对话交互
- 多主题支持：CSS 变量系统
- 应用注册表：统一应用中心
- 新手指引：Onboarding 流程

## 踩过的坑与解决方案

| 问题描述 | 解决方案 |
|---------|---------|
| FSRS 算法与现有题库数据结构不匹配 | 设计了统一的复习记录适配器，兼容不同题型 |
| 专注工作流状态管理复杂 | 引入 FocusWorkProvider，用 reducer 模式管理状态 |
| 多主题 CSS 变量冲突 | 建立 `--ark-*` 命名空间，所有组件使用语义化类名 |
| 前后端类型定义不一致 | 用 TypeScript 类型作为单一数据源，后端生成对应 schema |
| 新增学习模块改动太多 | 设计应用注册表机制，新增应用只需声明配置 |
