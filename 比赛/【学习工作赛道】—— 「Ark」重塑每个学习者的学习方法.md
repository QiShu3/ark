**0. 先和大家打个招呼吧 👋**

* **你是谁：** 一名在读研究生

* **你是怎么用 TRAE 把 Demo 做出来的：** 

充满想象力，然后把想象化为现实。在正式让Trae写代码前现在脑海中构建好自己想做的项目的蓝图，然后再通过 superpower 的brainstorm skill 和 Trae进行讨论，在讨论过程我会发现自己想象的项目设定往往是过于抽象且不实际的，比如说我想开发一个工作流，我觉得就是简单地按部就班进行下去，但是 Trae 会问我 这个工作流 的输入输出是什么样的呢？数据模型又是什么样的呢？又要怎么和其他模型进行互动的呢？让我发现，一个再简单的东西也有其运行的逻辑所在，这就是所谓的“麻雀虽小，五脏俱全”。因此，在不断地和Trae的讨论中，越来越多的项目模块搭建出来了，我的想象也逐渐变成了现实。这是一次伟大的实践，也是项目的第一步。
实践是检验真理的唯一标准。自从AI出现以来，有不少的声音认为AI有很多幻觉，说的话不可信，无法用以实践中。AI存在幻觉确实不是完全主观的认识，而是确实存在的客观现象，因此AI搭建出来的产品也必然存在幻觉。为了克服AI的幻觉，以保证功能的正常实现，测试必不可少。单元测试、集成测试、冒烟测试这些传统但十分有效测试方法保证了 AI 开发的产品可以正确地运行。AI时代自然也有新的测试方法，Trae Work有个内置浏览器的功能，每次进行完一次大的功能迭代，我都会用之前写好的提示词（包含过程、测试用的账号密码，上传用的文件，下载保存的文件夹等等）让AI模拟真实用户完完整整地运行一系列操作，保证 产品 不会因为某些功能开发异常出现难以发现的BUG。
好的美学设计让产品变得更优雅。当项目终于按照自己的想象跑起来后，我十分兴奋推荐给身边的同学用用看，但他们提出一个很关键的问题，产品功能本身做的不错，但真的.....不怎么好看。听到这句话的我如醍醐灌顶，AI的出现虽然大量减少了用于开发和测试的时间，但是美学本身也很重要，这恰恰是AI难以替代的。好在 Trae Work 有个 Design 功能，我可以不断重新设计一套套的UI，然后不断请教身边艺术专业的同学，也让AI帮忙评价我的产品美学，慢慢提高自己的审美水平。

设计-开发-测试 是我在用Trae 做项目时认为最为重要的三要素，这三者也恰好被  Design、Code和Work三个模式所覆盖。根据不同需求使用不同功能，按部就班、耐心地和AI沟通，Demo就会一步步呈现出来了。

**1. Demo 简介**

* 是什么：网站

* 面向谁：学生，科研人员以及任何想学习新事物、或者对当前学习的东西更近一步的人。

* 主要功能：Ark 的核心创新是 **Fork 机制**——当练习正确率未达标时，系统不是简单地让你"重做一遍"，而是自动诊断薄弱环节，推荐针对性的扩展学习路径，形成「发现问题 → 分析问题 → 解决问题」的闭环。以下功能围绕这一机制协同运转。
	1. **学习进度展览**：首页以「事件」为核心组织学习，左侧展示当前学习事件的倒计时和整体进度，右侧实时显示当前阶段计时、今日进度百分比、待完成任务与日程日历，底部快捷入口通向数据分析、成就系统和应用中心，让学习者一眼掌握全局。
	 ![[Pasted image 20260704164622.png]]
	2. **自定义独属于自己的学习路线**：通过「编辑编排」功能，学习者可以从题库中自由挑选专注工作（如长难句拆解、阅读理解训练、同义替换识别等），拖拽调整执行顺序，组合成个性化的学习工作流。每个工作流支持命名和反复修改，真正实现"我的学习我做主"。
	 ![[Pasted image 20260704164738.png]]
	3. **进行不同种类的学习**：支持三大练习类型，覆盖考研备考全场景——
		1. **选择练习**：左侧展示阅读文章，右侧呈现选择题，系统实时记录专注状态，答完即出结果。
		![[Pasted image 20260704164823.png]]
		2. **输入练习**：支持写作、翻译等主观题训练，提供真题原图与答题输入框，适合考研英语大小作文等场景。
		![[Pasted image 20260705233752.png]]
		3. **单词记忆**：采用间隔重复算法，先展示单词让学习者回忆释义，再根据掌握程度（没记住 / 有点难 / 记住了 / 很轻松）自动安排后续复习节奏。
		![[Pasted image 20260705233820.png]]
	4. **学习过程结算**：完成一轮工作流后，系统生成通关结算报告，汇总总专注时间、完成任务数、扩展学习触发次数和最佳正确率，并以时间轴形式展示完整学习路径，每个节点标注用时、答题数和正确率，让每一分努力都可视化。
		![[Pasted image 20260705233913.png]]
	5. **Fork 机制**：当一轮练习结束后正确率未达标时，系统自动分析薄弱环节并推荐针对性的扩展学习路径（如"不会单词？→加强词汇积累"、"长难句看不懂？→突破句子结构"、"针对训练→精准提升正确率"），学习者可选择"再来一轮"或跳转到推荐练习，实现从"发现问题"到"解决问题"的闭环。下图展示了完整的学习路径时间轴：从英语二阅读出发，正确率未达标后 Fork 出背单词和长难句两条支线，完成后自动回到原主线继续推进。
		![[Pasted image 20260705234052.png]]
		![[Pasted image 20260705233913.png]]
	6. **AI 助手"莫宁"**：内置 AI 学习助手，提供快捷提问入口（"给我介绍一下这个系统"、"你是谁？"、"如何开始使用？"），支持自然语言对话，帮助学习者快速上手并随时解答学习过程中的疑问。
		![[Pasted image 20260704165425.png]]
	7. **其他功能**：
		1. **安排管理**：统一管理任务与日程，支持按"全部 / 今日 / 待确认 / 重复"筛选，左侧显示今日任务列表及完成状态，右侧展示日程详情与截止时间，让学习计划井井有条。
		![[Pasted image 20260706101845.png]]
		2. **成就系统**：分为「当前事件成就」和「全局成就」两个维度——事件成就跟踪单次学习目标的推进（首次推进、连续3天、交付前夜等），全局成就记录长期累计进度（总专注10小时、连续使用7天等），通过游戏化激励持续学习。
		![[Pasted image 20260704165456.png]]

**2. Demo 创作思路**

* 灵感来源：灵感来源于《刻意练习》这本书，它认为 进步的关键在于练习的“质量”，而非单纯的时间堆积，而我希望通过AI来提高练习的“质量”。

* 想解决的问题：《刻意练习》中有提到学习中的几个重要概念：有目的的学习、保持专注、及时反馈、突破舒适区。本Demo将着重于一一解决这些问题，尤其为**及时反馈**这一及其重要但又往往被忽略的步骤，在很少人会对自己重复的练习进行复盘，一是没有自觉性，二是不知道怎么复盘，在本demo中，每一次练习的专注工作都会存档并检测练习质量，同时引入了重要的**Fork**机制，以保证自己练习的质量，保证每一分一秒都落在实处。

* 为什么做这个方向：智者向内寻求力量。我们总让AI去干活，但为了保证我们命令的有效性，我们同时也要进行不断地学习，让AI辅助我们提高自身水平也是为未来让AI生产力提升的重要关键之处。3AI对各个行业都进行了冲击，不少行业都利用AI进行了大大小小的重构，我认为学习本身也需要面向AI进行一次重构。其次，学习本身就是由大量的重复工作和少量但同样重要的思考过程构成的，AI的特性恰好可以满足这些需求，辅助我们一次又一次的练习，学会日新月异的各种新兴事物。
