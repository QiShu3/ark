## 初赛核心要求

### 提交物
1. **可交互 Demo** - 用 TRAE Work 或 TRAE IDE 开发
2. **Demo 作品帖** - 在初赛专区按模板发布

### Demo 作品帖必备内容
1. **Demo 简介** - 是什么、面向谁、主要功能（配截图）
2. **Demo 创作思路** - 灵感来源、想解决的问题、方向选择
3. **Demo 体验地址** - 三选一：
   - 部署的公开访问链接
   - 交互式 HTML 文件（Zip 打包上传）
   - 硬件赛道可用演示视频
4. **TRAE 实践过程** - 完整流程 + 关键步骤截图（≥3张）+ Session ID（≥3个）
5. 报名帖链接

### Session ID 获取
- TRAE 每段对话任务的唯一标识
- 双击 TRAE 的对话即可复制
- 用于证明作品由 TRAE 开发完成

## 评审维度（专业评审通道）

专业评审团按 4 个维度打分，综合得分 TOP 300 晋级复赛：

1. **创意与价值** - 解决真实问题的程度
2. **完成度与体验** - 核心功能是否跑通、体验如何
3. **TRAE 应用深度** - 用了 TRAE 哪些能力、过程是否真实
4. **表达与呈现** - 作品帖质量、截图、文档

### 基本要求
- Demo 与报名创意方向一致
- 基于 TRAE IDE 或 TRAE Work 完成
- 提供可体验地址
- 清晰展示核心功能与目标场景
- 参赛帖结构完整

## 提高入围概率的建议

1. **写真实场景** - 把想解决的问题讲具体，不空泛
2. **展示过程，而非只放结果** - 任务拆解、TRAE 能力应用、关键 Prompt、踩过的坑
3. **多用截图** - 开发关键步骤截图不少于 3 张
4. **保留 Session ID** - 不少于 3 个，证明真实性
5. **保证体验链接可用** - 提交前自己测试一遍
6. **内容原创、版权清晰**
