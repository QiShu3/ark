# 测试报告模板

## 1. 报告概述

本模板用于记录 AI Agent 的测试结果。测试报告应客观、准确地记录测试过程和发现的问题，为后续改进提供依据。

### 使用说明

1. 复制下方的"报告模板"章节
2. 填写测试概览信息
3. 记录每个测试场景的结果
4. 汇总发现的问题
5. 提出改进建议

---

## 2. 报告结构说明

### 2.1 测试概览

| 字段 | 说明 |
|------|------|
| 测试日期 | 执行测试的日期，格式：YYYY-MM-DD |
| 测试环境 | 测试使用的环境（本地开发、测试服务器等） |
| 测试人员 | 执行测试的人员或 AI Agent 名称 |
| 测试版本 | 被测试的代码版本或提交哈希 |
| 测试范围 | 本次测试覆盖的功能模块 |

### 2.2 测试结果摘要

使用以下格式汇总测试结果：

```
总场景数：X
通过：X (XX%)
失败：X (XX%)
阻塞：X (XX%)

按严重程度：
- P0 (阻塞)：X 个
- P1 (严重)：X 个
- P2 (一般)：X 个
- P3 (轻微)：X 个
```

### 2.3 详细测试结果

每个测试场景应包含：
- 场景编号和名称
- 前置条件
- 测试步骤
- 预期结果
- 实际结果
- 测试状态（通过/失败/阻塞）
- 截图（如有）

### 2.4 问题清单

记录发现的所有问题，包括：
- 问题编号
- 问题描述
- 严重程度
- 复现步骤
- 截图证据
- 关联的测试场景

### 2.5 建议

基于测试结果提出的改进建议，包括：
- 功能改进建议
- 流程优化建议
- 文档完善建议

---

## 3. 填写说明

### 3.1 如何记录测试结果

**状态标记：**
- ✅ **通过**：测试场景按预期工作
- ❌ **失败**：测试场景未按预期工作
- ⚠️ **阻塞**：无法执行测试（依赖问题、环境问题等）
- ⏭️ **跳过**：明确跳过的测试场景

**记录原则：**
1. 客观描述事实，不添加主观判断
2. 记录具体的操作步骤，便于复现
3. 区分"预期结果"和"实际结果"
4. 保留完整的错误信息

### 3.2 如何截图

**截图时机：**
- 测试开始前的初始状态
- 关键操作步骤的执行结果
- 发现问题时的错误状态
- 测试完成后的最终状态

**截图命名规范：**
```
screenshots/{场景编号}_{步骤描述}_{时间戳}.png

示例：
screenshots/TC001_login_page_20260625.png
screenshots/TC001_login_success_20260625.png
screenshots/TC002_error_dialog_20260625.png
```

**截图要求：**
- 截图应清晰可见
- 包含足够的上下文信息
- 问题截图应突出显示问题区域

### 3.3 如何描述问题

**问题描述结构：**
```
【问题标题】简明扼要地描述问题

【严重程度】P0/P1/P2/P3

【复现步骤】
1. 步骤一
2. 步骤二
3. 步骤三

【预期结果】描述应有的行为

【实际结果】描述实际的行为

【截图证据】screenshots/xxx.png

【环境信息】
- 浏览器：Chrome 120
- 操作系统：macOS 14.2
- 测试环境：本地开发

【其他信息】补充说明
```

**严重程度定义：**

| 级别 | 定义 | 示例 |
|------|------|------|
| P0 | 阻塞性问题，无法继续测试 | 系统崩溃、数据丢失 |
| P1 | 严重问题，核心功能不可用 | 登录失败、支付失败 |
| P2 | 一般问题，功能异常但有替代方案 | 显示错误、性能问题 |
| P3 | 轻微问题，不影响主要功能 | 文案错误、样式问题 |

## 4. 示例

### 4.1 测试场景示例

```
场景编号：TC001
场景名称：用户登录功能测试
前置条件：
- 用户已注册账号
- 测试环境可访问

测试步骤：
1. 打开登录页面
2. 输入用户名：testuser@example.com
3. 输入密码：Test123456
4. 点击"登录"按钮

预期结果：
- 登录成功
- 跳转到首页
- 显示用户头像

实际结果：
- 登录成功
- 跳转到首页
- 显示用户头像

测试状态：✅ 通过

截图：
- screenshots/TC001_login_page_20260625.png
- screenshots/TC001_login_success_20260625.png
```

### 4.2 问题记录示例

```
问题编号：BUG-001
问题标题：登录失败时未显示错误提示

严重程度：P2

复现步骤：
1. 打开登录页面
2. 输入用户名：invalid@example.com
3. 输入密码：wrongpassword
4. 点击"登录"按钮

预期结果：
- 显示错误提示："用户名或密码错误"
- 停留在登录页面

实际结果：
- 页面无任何响应
- 无错误提示
- 控制台显示 401 错误

截图证据：screenshots/BUG001_no_error_prompt_20260625.png

环境信息：
- 浏览器：Chrome 120
- 操作系统：macOS 14.2
- 测试环境：本地开发

其他信息：
- 刷新页面后重新操作可复现
- 网络请求返回 401 Unauthorized
```

## 6. 注意事项

1. **及时记录**：测试过程中发现问题应立即记录，避免遗忘
2. **客观描述**：只记录事实，不添加主观臆断
3. **保留证据**：截图和日志是重要的问题证据
4. **清晰明了**：问题描述应让开发人员能够理解和复现
5. **分类准确**：正确评估问题严重程度，避免过度或不足分类
