## 1. 功能概述

验证游客从登录、考研事件引导到进入预制子应用并启动刻意工作流的完整学习路径。

**核心能力：**
- 游客登录并完成考研 / 22408 事件初始化。
- 应用中心仅展示四个游客专属子应用。
- 每个游客子应用加载自己的工作流预设并可正常启动学习。

## 3. 测试场景

### P0 - 核心功能

#### 场景 S01：游客登录和事件引导

**优先级：** P0
**前置条件：** 前后端服务已启动；使用新浏览器会话，避免已有游客令牌。

**操作步骤：**

```
1. browser_navigate: 访问 http://localhost:5173
2. browser_snapshot: 确认登录页显示“游客体验”入口
3. browser_click: 点击“游客体验”
4. browser_snapshot: 确认进入首页且显示事件类型选择弹窗
5. browser_click: 选择“考研”
6. browser_snapshot: 确认显示目标专业选择弹窗
7. browser_click: 选择“22408”
8. browser_snapshot: 等待初始化完成，确认出现事件和首个气泡引导
9. browser_screenshot: 保存引导完成截图
```

**预期结果：**
- 游客登录成功，进入首页。
- 可依次选择“考研”和“22408”。
- 页面创建并显示“22408考研”主事件，气泡引导可继续交互。

#### 场景 S02：游客应用中心和子应用预设

**优先级：** P0
**前置条件：** S01 已完成。

**操作步骤：**

```
1. browser_navigate: 访问 http://localhost:5173/#/apps
2. browser_snapshot: 确认应用中心仅显示英语二、数学二、政治、408四个游客子应用
3. browser_click: 进入英语二子应用
4. browser_snapshot: 确认题库、专注工作配置和工作流编排区域已加载
5. browser_snapshot: 确认工作流列表出现“英语二工作流”
6. browser_screenshot: 保存英语二子应用截图
```

**预期结果：**
- 应用中心显示四个游客专属子应用。
- 英语二子应用能加载游客题库和“英语二工作流”预设。

#### 场景 S03：游客启动预制学习工作流

**优先级：** P0
**前置条件：** S02 已完成。

**操作步骤：**

```
1. browser_click: 点击英语二工作流的启动入口，或点击其专注工作配置的启动入口
2. browser_snapshot: 确认未出现“该功能仅对管理员开放”错误
3. browser_snapshot: 确认进入活动专注工作流或英语学习内容界面
4. browser_screenshot: 保存工作流启动后的截图
```

**预期结果：**
- 游客可启动自己的配置或预设。
- 工作流进入活动状态，显示英语题库学习内容。

### P1 - 交互功能

#### 场景 S04：其他子应用预设隔离

**优先级：** P1
**前置条件：** S01 已完成。

**操作步骤：**

```
1. browser_navigate: 分别访问数学二、政治、408游客子应用
2. browser_snapshot: 分别确认工作流区域显示数学二工作流、政治工作流、408工作流
3. browser_screenshot: 保存至少一个非英语子应用截图
```

**预期结果：**
- 每个子应用只显示属于自身的工作流预设。
- 不显示其他子应用的工作流。
