## 1. 功能概述

工作流编排是刻意学习流模块的核心功能之一，允许用户将多个专注工作配置按顺序组合成一个完整的学习工作流，实现多题型、多题库的串联练习。

**核心能力：**
- 新建编排：从已有专注工作配置中选择多个，按顺序组成工作流
- 编辑编排：调整编排中的专注工作顺序、增删配置、修改名称
- 删除编排：移除不需要的编排
- 启动编排：一键启动多配置组合工作流，系统按顺序执行
- 预览编排：查看编排详情后再决定启动或编辑

## 3. 测试场景

### P0 - 核心功能

#### 场景 S01：新建工作流编排

**优先级：** P0  
**前置条件：** 系统中至少存在 2 个以上的专注工作配置

**操作步骤：**

```
1. browser_navigate: 访问 http://localhost:5173/#/deliberate-workflow
2. browser_snapshot: 确认页面加载完成，定位"工作流编排"区域
3. browser_click: 点击"新建编排"按钮
4. browser_snapshot: 确认编排编辑器弹窗打开
5. 验证：弹窗包含左栏（可选专注工作列表）和右栏（已选队列）
6. browser_click: 在左栏选择第一个专注工作，添加到右栏
7. browser_click: 在左栏选择第二个专注工作，添加到右栏
8. browser_snapshot: 确认右栏有 2 个专注工作
9. browser_type: 在编排名称输入框输入"测试编排-自动化测试"
10. browser_click: 点击"保存"按钮
11. browser_snapshot: 确认弹窗关闭，编排列表中出现新编排
```

**预期结果：**
- 编排编辑器弹窗正常打开，左右两栏布局正确
- 可以从左栏选择专注工作添加到右栏
- 右栏显示已选的专注工作，顺序正确
- 输入名称后可以保存
- 保存后编排列表中出现新创建的编排

**验证方法：**
- 截图保存编排编辑器状态
- 截图保存保存后的编排列表

#### 场景 S02：启动工作流编排并运行

**优先级：** P0  
**前置条件：** 系统中存在至少一个包含 2 个以上专注工作的编排

**操作步骤：**

```
1. browser_navigate: 访问 http://localhost:5173/#/deliberate-workflow
2. browser_snapshot: 找到"工作流编排"区域中的目标编排
3. browser_click: 点击编排的"启动"按钮
4. browser_snapshot: 确认工作流开始运行（页面跳转或弹窗提示）
5. browser_snapshot: 确认第一个专注工作开始执行
6. 完成第一个专注工作的几道题目
7. browser_snapshot: 确认第一个专注工作完成后，自动切换到第二个
8. 完成第二个专注工作
9. browser_snapshot: 确认工作流完成结算
10. browser_navigate: 返回 http://localhost:5173/#/deliberate-workflow
11. browser_snapshot: 确认"组合工作流记录"中出现新的完成记录
```

**预期结果：**
- 点击启动后工作流正常开始运行
- 按编排顺序依次执行各个专注工作
- 每个专注工作完成后自动切换到下一个
- 全部完成后展示结算页面
- 运行记录中保存本次执行记录

**验证方法：**
- 截图保存每个阶段的运行状态
- 最终验证运行记录列表

### P1 - 交互功能

#### 场景 S03：编辑工作流编排

**优先级：** P1  
**前置条件：** 系统中存在已有的编排

**操作步骤：**

```
1. browser_navigate: 访问 http://localhost:5173/#/deliberate-workflow
2. browser_snapshot: 找到目标编排，点击"编辑"按钮
3. browser_snapshot: 确认编排编辑器打开，显示当前配置
```

**预期结果：**
- 编辑弹窗打开并正确加载当前编排配置
- 可以调整专注工作的顺序
- 可以移除已选的专注工作

- 修改名称后保存生效

**验证方法：**
