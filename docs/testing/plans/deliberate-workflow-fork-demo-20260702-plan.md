## 1. 功能概述

本次测试验证刻意学习流（Deliberate Workflow）的完整 Fork 机制，展示考研英语阅读理解训练的多层级分支学习路径。

**核心能力：**
- 阅读理解主任务答题与结算
- 未达标时自动 Fork 到长难句结构拆解子任务
- 长难句子任务未达标时继续 Fork 到定语从句专项
- 子任务完成后返回主任务继续
- 最终结算与学习路径展示
