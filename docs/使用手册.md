# Ark 专注工作流使用手册

本手册详细介绍了 Ark 学习平台中的**专注工作流 (Focus Work Workflow)** 核心功能、界面结构及操作指南。专注工作流旨在帮助用户沉浸式地完成每日学习任务（如背单词、阅读理解等），同时提供灵活的执行控制与限制拦截。

---

## 1. 专注外壳容器 (Focus Work Modal Shell)

专注外壳容器（[FocusWorkModalShell.tsx](file:///Users/qishu/Project/ark/frontend/src/components/focus-work/FocusWorkModalShell.tsx)）是专注工作流的全屏交互界面，为不同的子应用（背单词、阅读理解、自定义专注任务）提供统一的执行外壳和全局控制。

### 1.1 界面布局与核心元素
- **顶部控制栏 (Header)**：
  - **任务标题与副标题**：左侧动态展示当前正在进行的任务（如“今日单词”、“开始复习”、“任务专注”）及其归属分类。
  - **专注状态标签 (Status Badges)**：
    - <span style="color:#10b981;font-weight:bold;">正在记录专注</span> (绿色)：表示当前正在正常进行专注，且该时段的时间会被记录进系统专注时长。
    - <span style="color:#d97706;font-weight:bold;">本次工作将不记录在专注时间中</span> (黄色)：表示已进入专注界面，但用户在进入前选择了“不记录直接进入”。
    - <span style="color:#0284c7;font-weight:bold;">已暂停</span> (蓝色)：表示专注已暂停。
  - **核心操作按钮**：
    - **暂停/继续专注**：点击后切换暂停状态。暂停时，内容区会呈现模糊遮罩，阻断交互，并显示“专注已暂停”卡片。
    - **放弃本阶段**：用于中途退出当前专注阶段，需用户进行二次确认。
    - **结束本轮专注**：主动结算并结束当前轮次的专注。
- **主内容区 (Content Area)**：
  - 动态渲染当前绑定的子应用组件（如 [VocabTodayFocusWork.tsx](file:///Users/qishu/Project/ark/frontend/src/components/Vocab/VocabTodayFocusWork.tsx)、[ERCReviewFocusWork.tsx](file:///Users/qishu/Project/ark/frontend/src/components/ERC/ERCReviewFocusWork.tsx) 或自定义任务组件）。

## 2. 任务上限拦截遮罩 (Pre-check Interceptor Overlay)

为了防止用户重复提交已完成的每日上限任务，系统在启动专注阶段时引入了“前置校验拦截”机制。

### 2.1 触发条件
- 当用户点击开始某个专注任务，且该任务在当天已经达到了完成次数上限（`is_task_completed_today === true` 且未强制开始）时，系统会自动弹出此拦截遮罩（在 [FocusWorkProvider.tsx](file:///Users/qishu/Project/ark/frontend/src/components/focus-work/FocusWorkProvider.tsx) 中实现）。

### 2.2 界面元素与操作选项
- **警告图标**：顶部的黄色警告符号 ⚠️。
- **提示文案**：明确告知用户“该任务今日已达完成上限。您今天已经完成了此项学习任务。您可以选择跳过此阶段进入下一阶段，或者仍然强制开始该任务。”
- **操作按钮**：
  - **仍然开始该任务**：忽略上限拦截，强制进入子应用的专注操作状态。
  - **直接跳过进入下一阶段**：跳过当前任务阶段，自动推进到下一工作流阶段。

## 3. 专注成功结算遮罩 (Success Settlement Overlay)

当用户在子应用中完成了所有的专注学习内容时，系统会显示专注成功结算遮罩，提供一键结算和加练的选项。

### 3.1 触发条件
- 子应用完成所有操作后（例如背完今日单词，或做完复习题），触发子应用的完成回调，令外壳的 `isSubAppFinished` 状态置为 `true`。

### 3.2 界面元素与操作选项
- **成功图标**：顶部的庆祝彩带 🎉。
- **提示文案**：展示“今日专注任务已圆满完成！太棒了！您已完成该专注任务的所有内容。”
- **操作按钮**：
  - **标记任务已完成并进入下一阶段**：保存本次学习成果，更新数据库任务状态，并流转到下一个专注工作流阶段。
  - **再来一次 (加练)**：重置子应用状态，允许用户在不离开该阶段的情况下重新练习。

## 4. 开发者测试与验证指南

如果您需要在本地测试或复现上述三个状态：
1. **正常操作状态**：登录测试账号（`qishuadmin` / `Password123!`），在首页找到“开始工作流”或任意专注任务，选择“记录并进入”即可打开 `FocusWorkModalShell` 的正常专注态。
2. **上限拦截状态**：在数据库或管理面板中将该任务的今日状态改为已完成（或通过调接口完成一次），然后再次点击开始该任务，即可触发 Pre-check Interceptor。
3. **成功结算状态**：进入学习页面后，答完所有词汇或题目，或者手动触发子应用的完成事件，即可在当前外壳内渲染出 Success Settlement 界面。
