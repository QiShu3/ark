# 事件模板与事件工作台统一设计

## 概述

本设计把“事件模板”重新定义为“事件工作台的预设快照”。

用户看到的不是一套独立的“计划模板 / 计划项目”系统，而是同一套事件工作台在两种模式下的表现：

- `模板模式`：编辑将来新建事件时要默认填入的内容
- `工作台模式`：编辑某一个具体事件的实时内容

两者共享同一套可编辑内容和视觉结构。差别只在于：

- 模板模式不显示运行态结果
- 工作台模式会继续显示已创建安排和成就摘要

模板允许写入具体日期值，尤其是事件层字段：

- 事件名称
- 开始日期
- 到期时间
- 是否主事件

这些值是可以直接硬编码的，不要求用户先理解相对推算。

## 已确认的产品决策

- 事件工作台保留，且仍然是事件的主入口。
- 模板内容要和事件工作台的可编辑内容一致。
- 不再把“计划模板 / 计划项目”作为面向用户的核心概念。
- 模板可以保存具体的事件名称、开始日期、到期时间、是否主事件。
- 模板不保存运行结果，例如已创建任务、已创建日程、成就摘要。
- 套用模板时，先回填事件字段，再进入工作台。
- 事件层日期使用具体日期 / 时间，不要求模板用户去理解日期推算。

## 目标

- 让模板看起来就是工作台的预设版，而不是另一套平行系统。
- 让用户能用模板快速创建一个事件，并把事件字段直接带入。
- 保留事件工作台已有的完整编辑能力和运行态展示。
- 尽量复用现有事件工作台组件和数据流，降低改动面。

## 非目标

- 不新增独立的“计划项目”产品层。
- 不把模板做成独立路由页。
- 不做 AI 自动拆解或智能排期。
- 不把已创建任务 / 日程写入模板。
- 不要求模板支持复杂版本历史或协作编辑。

## 概念定义

### 事件模板

事件模板是一个可复用的预设快照，保存的是“新事件默认长什么样”。

它包含：

- 事件头部字段的默认值
- 工作台可编辑内容的默认值

它不包含：

- 已创建安排
- 成就摘要
- 其他运行态统计

### 事件工作台

事件工作台是某个具体事件的实例页面。

它包含两类内容：

- 可编辑内容：事件信息、工作台内容
- 运行态内容：已创建安排、成就摘要

### 工作台内容

工作台内容指的是工作台里真正要编辑、能够被模板复用的那部分内容。

它和模板模式共享同一套结构和编辑方式，但不会把“计划项目”作为单独术语暴露给用户。

## 用户体验

### 1. 创建事件时套用模板

在事件编辑弹窗中：

- 模板选择器改成“事件模板”
- 选择模板后，优先回填事件名称、开始日期、到期时间、是否主事件
- 用户可以继续手动调整这些字段
- 点击确认后，创建事件并进入该事件工作台

如果当前表单里已经有用户输入，模板默认只补空白字段；若要整体覆盖，交互上要明确提示。

### 2. 模板编辑入口

右侧齿轮入口继续保留，但进入的是“模板工作台”。

模板工作台的编辑区域应和事件工作台的可编辑区域一致：

- 事件信息
- 工作台内容

模板工作台不显示：

- 已创建安排
- 成就摘要

### 3. 从工作台另存模板

在事件工作台中，用户可以把当前状态另存为模板。

另存时保存：

- 当前事件的头部字段默认值
- 当前工作台内容快照

不保存：

- 已创建安排
- 成就摘要

### 4. 回写源模板

如果当前工作台来源于某个模板，用户修改后可以回写源模板。

回写时同步：

- 模板的事件默认值
- 模板的工作台内容快照

## 数据模型

### 模板元数据

模板需要补齐事件层默认值：

- `default_event_name`
- `default_start_date`
- `default_due_at`
- `default_is_primary`

这些字段允许为空，表示模板只提供工作台内容，不强制预填事件头部。

### 模板内容快照

模板内容仍然保存一组可复用的工作台内容记录。

这组记录的职责是：

- 让模板模式展示出和工作台一致的编辑内容
- 让模板套用后能还原出同一份工作台内容

实现上可以继续沿用现有模板内容记录表，但语义要从旧的“计划项目”改成“工作台内容快照”。

内部仍可保留用于复用的相对定位信息，但这不再作为用户面向概念出现。

### 运行态数据不入模板

以下内容不写入模板：

- 已创建任务
- 已创建日程
- 成就摘要
- 其他运行态统计

## API 设计

### 模板 CRUD

现有模板接口扩展为支持事件默认值。

创建 / 更新模板时，除了模板名称、说明和内容快照，还要支持：

- `default_event_name`
- `default_start_date`
- `default_due_at`
- `default_is_primary`

### 套用模板

套用模板时：

1. 先把模板的事件默认值回填到事件表单
2. 再把工作台内容快照实例化到当前事件
3. 打开该事件的工作台

### 另存为模板 / 回写模板

从事件工作台保存模板时：

- 读取当前事件头部字段
- 读取当前可编辑工作台内容
- 生成一份模板快照

## 兼容与迁移

- 旧模板没有事件默认值时，继续可用，只是不会自动预填事件头部。
- 旧模板内容继续可读，先按现有数据展示。
- UI 文案逐步从“计划模板 / 计划项目”切到“事件模板 / 工作台内容”。

## 验证标准

实现后至少验证以下场景：

- 选中模板后，事件名称、开始日期、到期时间能被回填
- 模板编辑界面和事件工作台的可编辑区保持同构
- 模板不包含已创建安排和成就摘要
- 从工作台另存模板后，再套用回来，编辑区内容一致
