# 背单词专注工作 UI 重新设计方案（草图）

## 一、现状问题分析

当前 UnifiedFocusWork 闪卡模式的问题：

1. **视觉重心弱** — 大卡片里内容稀疏，单词不够突出，像一个空盒子
2. **层次感不足** — 所有元素都是扁平的，没有明确的视觉层级
3. **交互反馈平淡** — 揭示答案只是简单的显示/隐藏，没有仪式感
4. **评分按钮简陋** — 底部只有两个按钮（记住了/没记住），缺少四档评分的丰富信息
5. **进度信息单薄** — 只有「进度：X / Y」一行文字，没有进度条或可视化
6. **沉浸感不够** — 背单词应该是专注、沉浸式的体验，当前界面太「工具化」

---

## 二、设计方向

**关键词**：沉浸、专注、纸质卡片质感、微动效、呼吸感

**风格基调**：
- 保留 `--focus-work-*` 变量体系，与整体一致
- 强化「单词卡片」的物理感 — 像一张精致的实体单词卡
- 增加微动效 — 入场、揭示、评分都有细腻过渡
- 信息分层 — 重要信息大而突出，次要信息弱而不抢
- 左右手操作友好 — 评分按钮靠下，方便拇指点击

## 四、核心模块详细设计

### 1. 顶部信息栏

```
┌─────────────────────────────────────────────────────┐
│  背单词                                              │  ← 小字 uppercase，tracking-widest
│  今日单词                        ████████░░  6 / 10  │  ← 标题 + 进度条 + 数字
└─────────────────────────────────────────────────────┘
```

**改动点：**
- 进度从纯文字改为**进度条 + 数字**组合
- 进度条用 `--focus-work-emerald-*` 色系，有渐变填充
- 数字放在进度条右侧，更紧凑
- 整体高度更矮，给卡片区域留出更多空间

---

### 2. 单词卡片区（核心）

这是最重要的视觉区域，要做成「一张精致的单词卡」。

#### 未揭示状态

```
┌─────────────────────────────────────────────────────┐
│  🔊                                                  │
│      (发音按钮，圆形，悬浮在卡片左上方)               │
│                                                     │
│              a b u n d a n t                        │  ← 6xl 大字，字间距放宽
│                                                     │
│              US /əˈbʌndənt/                         │  ← 等宽字体，muted 色
│              UK /əˈbʌndənt/                         │
│                                                     │
│         ─────── ● ───────                          │
│                (脉冲绿点)                            │
│                                                     │
│          先在脑中回忆释义                            │  ← faint 色，小字
│                                                     │
│              [ 显示释义 ▼ ]                         │  ← 胶囊按钮，带呼吸感
│                                                     │
└─────────────────────────────────────────────────────┘
```

**设计细节：**
- **单词字号**：从当前的 5xl 提升到 6xl-7xl，加粗，增加字间距（`tracking-wide`），让单词成为绝对视觉中心
- **音标**：等宽字体，muted 色，US/UK 分行显示，更清晰
- **发音按钮**：移到卡片左上角（而不是和单词并排），释放单词的视觉空间
- **分隔线 + 脉冲点**：保留，但加宽两侧的线，让呼吸感更强
- **揭示按钮**：胶囊形，有微妙的呼吸动画（透明度微微脉动），引导用户点击
- **卡片背景**：径向渐变光晕 + 轻微的 noise 纹理，增加质感

#### 揭示状态（点击「显示释义」后）

```
┌─────────────────────────────────────────────────────┐
│  🔊                                                  │
│                                                     │
│              a b u n d a n t                        │  ← 保持不变
│              US /əˈbʌndənt/                         │
│                                                     │
│         ─────── ● ───────  ← 脉冲点变亮             │
│                                                     │
│  adj. 丰富的，充裕的，大量的                         │  ← 2xl-3xl，中号字
│      abund（丰富）+ ant（形容词后缀）               │  ← 词根词缀辅助记忆（可选）
│                                                     │
│  📖 例句                                            │
│  "We have abundant evidence..."                    │  ← 关键词高亮
│   我们有充分的证据…                                 │
│                                                     │
│  ✅  正确: 12  ·  ❌  错误: 3  ·  已复习 15 次      │  ← 学习数据统计
│                                                     │
│              [ 收起释义 ▲ ]                         │
│                                                     │
└─────────────────────────────────────────────────────┘
```

**揭示动画**：
- 不是简单的显示/隐藏，而是**从分隔线处向下展开**的效果
- 释义文字有淡入 + 轻微上移的入场动画
- 例句区域有 0.1s 的延迟，营造层次感

**新增内容**：
- **词性标签**：释义前加词性（adj./n./v. 等），用颜色区分
- **词根词缀**：可选显示，帮助记忆（如果数据里有）
- **例句区**：带引号装饰，关键词高亮（绿色）
- **学习统计**：正确数、错误数、复习次数，用图标 + 数字的形式，底部一行

---

### 3. 评分按钮区（四档）

从两档改为四档评分，更符合 FSRS/Anki 的记忆模型，也让界面更丰富。

```
┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐
│  Frown   │  │  Meh    │  │  Check   │  │  Rocket  │  ← 图标（大一号）
│          │  │         │  │          │  │          │
│  没记住   │  │ 有点难  │  │ 记住了   │  │ 很轻松   │  ← 主标签
│  今天复习 │  │ 短期复习│  │ 正常间隔 │  │ 延长间隔 │  ← 副提示（小字）
│    [1]   │  │   [2]   │  │   [3]    │  │   [4]    │  ← 快捷键徽章
└──────────┘  └──────────┘  └──────────┘  └──────────┘
   玫瑰红        琥珀黄        翠绿色        天蓝色
```

**设计细节：**
- 四个按钮等宽等高，圆角 `rounded-2xl`
- 每个按钮有**图标 + 主标签 + 副提示 + 快捷键**四层信息
- 图标在上方，更大更醒目（24-28px）
- 默认状态是浅底色 + 边框
- Hover 状态：上浮 + 对应色系背景变深 + 边框变深
- 点击状态：缩放 + 颜色填充
- 四个按钮分别对应 rose/amber/emerald/sky 四个色系

**移动端适配**：
- 大屏幕：四列并排
- 小屏幕：两行两列（2x2 网格）

---

### 4. 快捷键提示

```
⌨️  快捷键：[1] 没记住 · [2] 有点难 · [3] 记住了 · [4] 很轻松 · [Space] 显示释义
```

- 放在最底部，居中
- 用更精致的图标（⌨️）代替之前的灯泡
- 信息更完整，所有快捷键都列出来
- faint 色，不抢视线

## 五、动效设计

### 入场
- 整卡从下方 20px 处淡入上浮
- 单词先出现，0.1s 后音标出现，0.2s 后分隔线 + 提示出现
- 营造「卡片翻到眼前」的感觉

### 揭示答案
- 分隔线脉冲点亮起
- 答案区域从分隔线处向下展开（高度从 0 到 auto）
- 释义文字淡入 + 轻微上移
- 例句比释义晚 0.1s 出现

### 评分点击
- 被点击的按钮：缩放 + 颜色填充（从边框式变为实心）
- 其他按钮：轻微变暗（降低不透明度）
- 0.3s 后整张卡片向左/右滑出，下一张卡片从另一侧滑入
- 根据评分方向滑动：
  - 没记住/有点难 → 向左滑出（暗示「回到队列前面」）
  - 记住了/很轻松 → 向右滑出（暗示「完成了，往前走」）

### 进度更新
- 进度条平滑增长
- 数字有计数动画

## 六、与现有系统的兼容

### 保留的接口
- `FlashcardFocusTemplate` 的 props 接口不变，可直接替换
- 四档评分（again/hard/good/easy）与现有 `FlashcardRating` 类型一致
- 使用 `--focus-work-*` CSS 变量，自动适配明暗主题

### 两种模式
- **UnifiedFocusWork 闪卡模式**：用新版设计（四档评分 + 精致卡片）
- **VocabTodayFocusWork**：可复用新的卡片组件

### 数据依赖
- 词根词缀：如果数据里没有，可以先不显示（fallback）
- 例句：已有数据支持
- 学习统计（正确/错误数）：已有数据支持

---

## 七、可选增强（P2）

1. **卡片翻转效果**：真正的 3D 翻转（CSS `transform: rotateY()`），正面是单词，背面是释义
2. **手势支持**：左滑 = 没记住，右滑 = 记住了，类似 Tinder
3. **进度环形图**：用环形进度条代替线性进度条，更有「完成一圈」的成就感
4. **专注计时显示**：卡片角落显示已专注时间
5. **每日目标动画**：完成最后一题时，有庆祝动效（confetti 或类似）
6. **单词收藏**：卡片上加入收藏按钮，难词可以加入收藏夹

---

## 八、与 StudyCard 的关系

现有 `StudyCard.tsx` 已经有不错的基础（径向渐变、脉冲点分隔、大字单词），可以在此基础上优化升级：

| 现有 StudyCard | 新版设计 | 改动 |
|---------------|---------|------|
| 单词 5xl bold | 6xl-7xl + tracking-wide | 更大更舒展 |
| 音标一行 | US/UK 分行 | 更清晰 |
| 发音和单词并排 | 发音移到左上角 | 释放空间 |
| 释义 3xl | 2xl + 词性前缀 | 更有层次 |
| 无评分按钮 | 四档评分按钮 | 核心新增 |
| 无进度条 | 顶部进度条 | 新增 |
| 无学习统计 | 底部统计行 | 新增 |
| 显示/隐藏切换 | 向下展开动画 | 更有仪式感 |

---

## 九、总结

这次重新设计的核心是**把「背单词」从一个功能界面变成一个沉浸式的学习体验**。

三个关键改进：
1. **视觉重心强化** — 单词更大更突出，卡片更有质感
2. **交互仪式感** — 揭示答案、评分切换都有细腻动效
3. **信息丰富度** — 四档评分、学习统计、进度可视化，让用户清楚知道自己的状态

整体保持 `--focus-work-*` 设计语言，与结算页、预览页形成一致的「专注工作」视觉体系。
