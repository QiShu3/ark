# ark项目的哲学初稿

## 1. 我的理念
### 现有的
    万事万物都是有联系的，评价一个人不能离开他当时所处的环境和条件去评价，做一件事也是如此。
    而“事件”则是如此，“事件”是 ark 首先出现的概念，当你要决定做一件事的时候要确认你当前处于哪一个事件中，比如说你要通过某一场重要的考试，你当前就处于 高考、考研或者考公这个“事件”中。
    “事件”有开始时间和截止时间，在这其中的时间会给你人生中留下不可磨灭的回忆。
    “事件”有“安排”，“安排”就是你为了应付这次事件需要完成的“任务”和记录关键节点的“日程”。
    而“工作流”就是对“任务”的编排，“工作流”也是单次专注中的最小粒度，每次专注都必须要完成一次工作流，“工作流”把不同的任务，每日任务、每周任务、自定义任务、子应用任务通过某种算法编排在一起，然后用专注-休息-专注的循环去完成这些任务。
    “专注工作”是一个工作台，每次专注都会有工作台，在工作台下你无法做专注之外的事情。
    “事件”的持续时间很长，长到会让你感到无所适从，因此引入了“成就”来为你的“专注”更有反馈，你的每一步努力都会被“成就”所记录，并在合适的时机跳出来为你喝彩！
### 未有的
    我觉得“事件”还可以引进“主旋律”这一概念，即是背景音乐，在“事件”的整个阶段都有一首音乐作为“事件”的“主旋律”，这样，当你听到主旋律的时候，你就可以立马进入“专注”，并且在“事件”之后，每当你听到“主旋律”时，都会回想起那一个个挥洒汗水、奋笔疾书的日日夜夜。“主旋律”可以是自带的也可以是自主设定的。
    “主旋律”还有一个好处，在未来可能的“事件”发布会中，它可以作为重要的组成部分。

    “事件”也可以有“子事件”，“子事件”的内容和“事件”一致，也可以有“子事件”。
